# Anonymizer

Локальное приложение для анонимизации документов (DOCX, PDF, JPG/PNG)
перед загрузкой в ИИ. Заменяет ФИО, телефоны, email, адреса, паспорта,
ИНН, БИК и банковские реквизиты на псевдонимы вида `[Person_1]`.

## Запуск
- CLI:  `python main.py <files/folders>`
- GUI:  `python gui_main.py`
